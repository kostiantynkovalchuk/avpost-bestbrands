TASK: Full Russian translation audit and cleanup of AV Post bilingual HTML newspaper
Context
This is a single-file bilingual HTML newspaper (index.html) for Best Brands (ТОВ «БЕСТ БРЕНДС»). It has a Ukrainian/Russian language toggle system. Ukrainian is the default. Russian is activated by clicking «РУС» button in the masthead.
The bilingual system works like this:
html<span class="t" data-ua="Ukrainian text" data-ru="Russian text">Ukrainian text</span>
```
JavaScript swaps `.textContent` to `data-ru` when RUS is active.

## Problems to fix

### 1. HTML artifacts appearing as visible text in Russian mode
Some spans have broken `data-ua` attributes — the Ukrainian text leaked INTO the attribute value, causing raw HTML to appear on screen. Pattern to find:
```
data-ua="some text <span class="t" data-ua="..."
Any data-ua or data-ru attribute that contains <span, >, <, or another data- inside it is broken. Fix by rebuilding as a single clean span.
